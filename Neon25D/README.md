# 霓虹夜市 · 原生 2.5D · 骨骼动画与进阶版

Blender 4.5.2 LTS 建模 → GLB → Godot 4.7.2。使用立体模型、正交镜头、原生 3D 物理与动态灯光，玩法限制在水平面。

## 本机环境与启动

检查结果：Blender 安装于 `C:\Program Files\Blender Foundation\Blender 4.5`，显卡 NVIDIA RTX 4060；PATH、安装记录和常见目录中未发现 Godot / Unity / Unreal。已从 Godot 官方下载免安装 4.7.2 引擎，放在仓库根目录的 `tools/godot`（忽略提交）。不修改系统 PATH、注册表或其他项目。

- 双击本目录 `Start-Game.bat`：首次导入 GLB，然后以 Vulkan / Forward+ 启动游戏。
- 显卡不支持 Vulkan 或需要更低负载时，运行 `Start-Compatible.bat` 使用 OpenGL 兼容模式。
- 双击 `Open-Editor.bat`：打开可编辑 Godot 工程。
- Blender 源文件：`art_source/NeonMarket_Assets.blend`。
- 独立 Windows 运行包另行提供，内含已签名 Godot 运行时与游戏 PCK，无需安装 Blender / Godot 即可运行。

朋友首次克隆仓库后，可用 PowerShell 执行 `./Neon25D/scripts/setup_engine.ps1` 从官方网站下载同版本引擎。启动脚本也会在引擎缺失时调用此脚本。

- 17 个原创 Blender 模型：三种摊位、玩家、四类敌人、Boss、货箱和灯笼，以及售货机、烤串车、竹盆栽、长椅、垃圾桶和门架。
- 立体摊位、中文几何招牌、灯笼、彩色点光源、实体货箱、地板与毒池变体。
- 12 个街区；前三间固定入门战斗、组合战斗、免费回血与商店，随后随机战斗 / 宝藏 / 商店 / 事件，最终 Boss。
- 16 项强化，包含多重弹道、穿透、雷电链、冻结、爆炸、吸血和环绕刃；冻结 + 爆炸、环绕刃 + 吸血、雷电击杀回充冲刺可联动。
- 追击者、枪兵连射、突进者、蓄力坦克，以及预警轰击 / 扇形弹幕 / 冲锋 Boss。原生角色及子弹被 3D 碰撞体阻挡。
- 商店拉面不限量、枪管独立限购；敌人回血掉落与保底；Boss 奖励自动领取。
- 音效、伤害数字、Boss 血条、冲刺冷却、死亡重开、胜利结算、永久印记与角色 / 武器解锁。

这是独立的 Windows 原生进阶版。原网页 3.0 保留在仓库根目录。浏览器存档不会自动迁入 Godot；原生存档在 Godot `user://progress.cfg`，测试模式不保存进度。已迁移原版两项进阶强化、完整评级统计与骨骼动画，并接入 Godot 原生触控摇杆。当前交付仍为 Windows 版；Android / iOS 安装包和真机测试尚未完成。当前六类角色使用 Blender 骨骼蒙皮与导出动画，朝向由游戏控制。

## 资产工作流

在本目录运行：

```powershell
& 'C:/Program Files/Blender Foundation/Blender 4.5/blender.exe' --background --factory-startup --python art_source/build_assets.py
```

脚本以米为单位创建网格、材质与中文几何招牌，逐件导出 `assets/*.glb`，同时保存 Blender 资产库。脚本重建会覆盖这些生成文件；手工修改 .blend 后，应另存或手动导出相应模型，避免被下次重建覆盖。

碰撞体由 Godot 根据物件放置尺寸建立。摊位 2.8 × 2.4 × 1.7 米，货箱与角色胶囊有真实碰撞，子弹以连续射线检测掩体。

独立包使用官方未修改的 Godot 可执行文件作为运行时加载 PCK，非定制导出模板生成的精简 EXE；因此体积较大。官方运行时采用 MIT 许可，包内附 Godot 许可证。游戏资产与源码归本项目维护。

## 骨骼与分层动画

六类角色各有 16 根骨骼、Armature 蒙皮权重，以及 Idle、Walk、Shoot、Dash、Hurt、Death 六个动作，共 36 段导出动画。模型使用分段式低多边形肢体和刚性权重蒙皮，所有动作保存在 `.blend` 中，并作为 GLB 骨骼动画导入。

`animation_driver.gd` 使用导入的 AnimationPlayer 播放全身动作，复制并过滤射击动作的上半身骨骼轨道作为独立射击层，因此移动射击仍保留腿部行走。冲刺 / 受击 / 死亡有动作优先级，冻结暂停动画；暂停冻结动画与触控输入，死亡先播放动作再显示结算。敌人死亡模型短暂停留后移除。

## 进阶强化与履历

- 雷暴领域：印记 ≥8 且本局已有雷电链时进入强化池，只能选择一次。跳跃距离 5.5 → 7.5 米，雷电击杀冲刺回充 0.3 → 0.5 秒。
- 冰晶回响：印记 ≥12 且本局已有冻结和爆炸时进入强化池，只能选择一次。冰爆额外半径 1 → 2 米，伤害系数 80% → 120%。
- 多重弹丸、暴击、环绕刃等达到上限后不再进入三选一；卡片显示当前层数、实际前后数值，HUD 显示构筑与已成形联动。磁力强化现在持续增加拾取半径。
- 履历记录完成局数、通关数、累计击败、最高街区、单局最高击败、最快通关及最近十局。每局保留时长、评级、暴击数、受伤量与构筑。
- 通关评级 S：6 分钟内且受伤少于 100；A：10 分钟内；其他通关 B。失败按最高街区给 B（9 以上）、C（5 以上）、D。放弃本局不计结算，结算幂等防止重复统计。
- 原有印记、累计击败和通关数继续沿用。旧版未保存的统计不会凭空补造；新增统计从升级后开始记录。

## 夜市美术

湿润沥青程序材质、霓虹高光、Forward+ 辉光与环境遮蔽；背景楼面与窗灯、垂落灯串和电线、街边排水槽、售货机和竹盆栽，拉面热气与细雨。拉面摊、茶摊与电玩摊具有不同柜台道具。前景建筑采用剖开式处理，避免遮挡战斗街道。OpenGL 模式保留模型与灯光并降低后处理。

## 战斗反馈与遮挡优化 — 2026-10-25

- 枪口闪光、上半身动作重触发、枪械后坐、弹壳、撞墙火花、命中/暴击/击杀差异反馈；特效独立随机源，不影响掉落与暴击随机结果。瞬态粒子最多 120 个，自动回收。
- 暂停菜单可循环切换震动关闭 / 低 / 标准，暂停时相机归位；此设置保存在偏好文件，下次启动仍有效。
- 按正交相机真实平行射线检测角色脚、躯干和头部遮挡。静态网格淡到 18%，离开后恢复原材质与透明模式，碰撞体不变；遮挡时蒙皮网格显示青色轮廓。敌方子弹与预警忽略视觉深度，弹丸仍由物理掩体阻挡。
- 枪兵 0.65 秒锁定瞄准，抬枪后 0.12 秒出第一发，随后 0.22 秒间隔三连射，0.55 秒恢复；开火后不追踪玩家旋转。
- 坦克 0.85 秒蓄力、0.55 秒冲锋、0.9 秒恢复，冲锋路径与面向固定；蓄力/恢复不造成接触伤害。
- 突袭者 0.65 秒预警落点、0.45 秒起跳，落地范围 1.25 米造成一次伤害；空中与恢复不造成接触伤害。位移仍受墙体与掩体限制。
- 普通追击/枪兵受击短暂硬直，带 0.4 秒硬直间隔；坦克/Boss 的明确前摇不被随机受击动作覆盖。冻结暂停敌人攻击时钟与动画，Boss 地面轰击和预警共用状态机时钟。
- `scripts/combat_checks.gd` 检查连射延迟与锁定、冻结时钟、冲锋接触窗口、单次落地伤害、遮挡淡出/恢复、关闭震动与特效回收；源工程和最终 PCK 都使用严格入口验证。实机截图通过 `--capture-scene=combat` 可重复生成，为固定战斗演示场景。
