# 霓虹夜市 · 午夜突围 3.0

2D 俯视角夜市肉鸽。原生 Canvas + Web Audio，无第三方运行依赖、无需构建，可离线运行。

## 运行

Windows 双击 `开始游戏.bat`，或用 Chrome / Edge 打开 `index.html`。保留同目录的 `game.js`。

手机使用在线入口，或将整个项目部署到静态服务器：

```sh
python -m http.server 8000
```

浏览器访问 `http://localhost:8000`。手机与电脑在同一局域网时，访问电脑局域网 IP 对应的 8000 端口（取决于防火墙设置）。

原在线入口：[霓虹夜市](https://neon-night-market-rogue-1024.tangywave14.chatgpt.site)（ChatGPT 账户访问权限取决于该站点设置）。

| 动作 | 键鼠 | 触屏 |

## 游戏内容

- 前三街区固定为入门战斗、组合战斗、补给商店，其余街区随机安排：战斗、宝藏、两间独立商店、神秘交易与最终 Boss。
- 掩体摊车、错位窄道、毒水和 Boss 街口四种布局；所有布局均保留安全通路。
- 摊位与掩体阻挡玩家、敌人及双方子弹；冲刺和冲锋无法穿墙。敌人使用网格寻路绕开掩体。
- 敌人：带角追击者、三连射枪兵、短前摇突进者、长前摇冲锋坦克；最终 Boss 按扇形弹幕 → 落点轰击 → 冲锋轮换。起手有预警，方向 / 落点锁定；招式结束有 1.4～1.7 秒反击窗口，半血转换阶段时清除敌方弹幕。
- 16 种强化（两项进阶强化需印记及前置流派解锁）：原有基础强化，以及雷电链、叠层冻结、范围爆炸、吸血、环绕刃和暴击。可叠加组合，当前构筑显示在右侧。
- 拉面 ¥20，可反复购买（满血不会扣款）；枪管 ¥30，每间商店限购一次，伤害 +35%。购买后商店继续营业，也可离开再进入。
- 普通敌人有 18% 概率掉落 16 点生命补给；同一房间连续五次未掉落会保底。
- 伤害与暴击数字、拾取 / 受击 / 射击 / 升级等合成音效；音效可静音。
- Boss 死亡时，150 经验、100 代币及场上未捡奖励先自动收取，再结算。结算经验会提升最终等级，无需再选择已结束本局的强化。
- 暂停可继续、重新开始或返回主菜单；后两者放弃当前局，不发放结算奖励。

## 流派与战斗节奏

- 首关三名追击者，无毒池，清场自动收取补给与经验，保证至少一次升级并恢复 12 生命。
- 第二关引入一名枪兵，清场自动收取奖励并恢复 18 生命。
- 第三关固定商店，第一次进入免费恢复 30 生命；前两关代币足够购买拉面。奖励不能重复领取。
- 后续战斗使用有主题的敌人组合；新连射 / 冲锋起手共享间隔，强攻击结束保留短暂恢复时间。
- 冰爆清场：冻结敌人被子弹再次命中时，搭配爆炸弹产生冰爆，伤及周围可见敌人。
- 雷电回充：雷电击杀使冲刺冷却减少 0.3 秒；雷暴领域提高至 0.5 秒。
- 血刃共鸣：环绕刃配合吸血，近战命中同样获得治疗。
- 升级显示当前层数、实际前后变化和联动提示；早期选择保证至少一个玩法强化。

## 手机控制

左摇杆以落指位置为中心，提供连续死区重映射；右摇杆可选择小角度辅助瞄准。右上角“触控”支持死区 12% / 18% / 28%、紧凑 / 标准 / 大号摇杆和辅助开关，配置保存至浏览器。横屏将控制区叠放于边缘以扩大视野，支持全屏（取决于浏览器）及退出按钮。暂停会释放活动指针，恢复后可重新落指。

本轮真机触控和浏览器视觉 QA 尚未完成：当前 Work 设置关闭了本地浏览器控制。逻辑与结构测试通过不等同于真机手感验证。

## 成长、统计与评级

永久印记用于解锁选择，不再增加初始生命。旧印记数量保留。

| 印记门槛 | 解锁 | 取舍 / 前置 |
| --- | --- | --- |
| 0 | 信使、脉冲手枪 | 100 生命 / 220 速度；16 伤害 / 0.24 秒 |
| 2 | 巷口散射 | 7×3 伤害 / 0.38 秒，散布更宽 |
| 3 | 滑板游侠 | 85 生命 / 255 速度 |
| 5 | 穿巷长针 | 28 伤害 / 0.48 秒，穿透一名敌人 |
| 6 | 夜摊守卫 | 120 生命 / 190 速度 |
| 8 | 雷暴领域强化 | 已获得雷电链时进入升级池 |
| 12 | 冰晶回响强化 | 已获得冻结与爆炸弹时进入升级池 |

角色和武器在主菜单选择；门槛不消费印记。初始武器各有距离 / 射速取舍，默认角色生命始终为 100。

单局最高击败数、累计击败数、最高街区、通关次数、最快通关时间保存在浏览器 `localStorage`。结算面板显示本局时长、最高街区、等级、代币和暴击次数。

通关评级 S：6 分钟内且累计受伤少于 100；A：10 分钟内；其他通关为 B。失败时按最高街区给 B（9 区以上）、C（5 区以上）或 D。重新开始 / 返回主菜单不计入完成局数。

更换浏览器、运行地址或清除站点数据会影响存档。旧版本的永久印记和单局最高击败数沿用；旧版本没有记录的累计统计从零开始。

## 开发与验证

- `index.html`：页面、样式、HUD、触屏控制布局。
- `game.js`：状态、合成音效、物理碰撞、地图、战斗、成长、渲染与输入。
- `tests/game.test.cjs`：无第三方依赖的逻辑回归测试（Node.js 18+）。

```sh
node --check game.js
node --test tests/game.test.cjs
node tests/simulate.cjs
```

测试覆盖单次冲刺、连续购物、碰撞与穿透、质变强化、敌人行为、地形通路、掉落保底、Boss 奖励、持久化、暂停、触屏取消和音频合成。浏览器预览另行检查桌面 / 手机布局。

### 3.0 验证记录

24 项自动化回归测试通过；三组确定性自动控制器使用正常伤害、移动、拾取、升级与购物完成十二关，均抵达胜利结算。这是流程回归验证，不能用于推断真人胜率或难度已经平衡。测试控制器和种子在 `tests/simulate.cjs`，测试 DOM / Canvas 适配在 `tests/harness.cjs`。
