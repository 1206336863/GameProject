# 霓虹夜市 · 午夜突围

可离线直接运行的 2D 俯视角霓虹夜市肉鸽游戏。无需安装依赖、无需构建。

## 运行

双击 `开始游戏.bat`，或直接用 Chrome / Edge 打开 `index.html`。

## 操作

- 方向键 / WASD：移动
- 鼠标左键：瞄准并持续射击
- 空格：冲刺，短暂无敌
- E：与宝箱、商店、事件交互
- Esc：暂停 / 继续

## 内容

十二个街区随机排列，包含战斗、宝藏、商店、事件与最终 Boss 房。清场后沿右侧发光出口前进。
升级从三项随机强化中选择一项。四种普通敌人与最终弹幕 Boss，支持失败重开和胜利结算。
永久印记与最高击败数保存在浏览器 localStorage 中；更换浏览器或清除浏览器数据会影响存档。

## 项目结构

- `index.html`：完整 HTML / CSS / Canvas JavaScript 游戏源码
- `开始游戏.bat`：Windows 快捷启动
